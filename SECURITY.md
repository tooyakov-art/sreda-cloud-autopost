# Security

## Допустимо в этом public repo

- исходный код;
- workflow;
- утверждённые публичные тексты;
- AES-256-зашифрованные медиапакеты;
- документация без секретов и личных данных.

## Запрещено

- access/refresh tokens;
- app secret, 2FA и backup codes;
- cookies и browser profiles;
- пароль медиапакетов;
- незашифрованные фото/видео клиента;
- сырые WhatsApp/Instagram Direct переписки;
- номера телефонов и личные контакты, кроме уже утверждённых публичных контактов бренда;
- `.runtime`, ledgers, временные архивы и decrypted output.

## Secrets

Production secrets хранятся только в GitHub Actions Secrets. Если значение случайно появилось в commit, log или чате, его надо считать скомпрометированным и немедленно ротировать. Простого удаления строки недостаточно.

## Permissions

Workflow имеет минимальное `contents: read`. Расширять permissions можно только под конкретную проверенную необходимость.

## Публичные материалы

Шифрование защищает утверждённые медиа в репозитории от прямого просмотра. Во время job они расшифровываются только во временном GitHub-hosted runner и удаляются вместе с ним.

## Сообщение об инциденте

Не публиковать секрет в GitHub issue. Сообщить владельцу приватным каналом, указав только тип секрета, commit/run URL и время инцидента.
