# SREDA Cloud Autopost

Облачный автопубликатор SREDA через официальные Instagram и Threads API.

- Работает в GitHub Actions, даже когда рабочий компьютер выключен.
- Токены хранятся только в GitHub Secrets.
- Будущие изображения находятся в репозитории только в AES-256-зашифрованных архивах.
- Публикации защищены ключами идемпотентности.

Период текущего расписания: 23–31 августа 2026, часовой пояс Asia/Qyzylorda.
